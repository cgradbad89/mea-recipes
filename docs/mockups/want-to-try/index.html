Design proposal · static mockup

Want to Try

A review board for a personal “Want to Try” state in the existing MEA Recipes experience. This is intentionally static: it illustrates proposed states and hierarchy, not production behavior or data wiring.

Recommended direction: bookmark = Want to Try; heart = Favorite. The bookmark uses the same amber selection language as existing controls, but has its own icon, wording, and placement.

A · Recipe listing

Desktop: normal, selected, and filtered

The new chip joins the existing horizontal sort/filter row. The card control occupies the otherwise unused lower-right image corner; Add to Plan remains in its current upper-right location.

B · Recipe detail

Desktop: related to planning, distinct from Favorite

The existing heart stays in the title’s compact icon cluster. Want to Try joins the action row as an outlined secondary action next to Add to Plan, which better communicates intention than editing or a permanent saved favorite.
